# Diagn-stico-Interno-de-Procesos-y-Comunicaci-n
Estamos realizando un diagnóstico interno para identificar oportunidades de mejora en nuestros procesos, comunicación, herramientas y forma de trabajo.  El objetivo de este cuestionario es entender mejor cómo operamos hoy para poder hacer el trabajo más claro, más eficiente y más ordenado.
